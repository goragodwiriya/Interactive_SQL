Cheat Sheet

คำสั่ง SQL สำคัญที่พบบ่อย

SELECT ... FROM

เลือกคอลัมน์และอ่านข้อมูลจากตารางที่ระบุ

WHERE & LIKE

กรองข้อมูลตามเงื่อนไขทางตรรกะและค้นหาคำด้วย Wildcard (%)

INNER / LEFT JOIN

เชื่อมความสัมพันธ์และรวมข้อมูลจากหลายตาราง

GROUP BY & HAVING

จัดกลุ่มข้อมูลและกรองผลลัพธ์หลังคำนวณ Aggregate

INSERT / UPDATE / DELETE

เพิ่ม แก้ไข และลบข้อมูลออกจากตาราง (DML)

CASE WHEN ... END

เขียนเงื่อนไข If-Else เพื่อจำแนกประเภทข้อมูล

WITH cte AS (...)

สร้างตารางเสมือนชั่วคราวเพื่อแบ่ง Query ซับซ้อน

OVER (PARTITION BY ...)

คำนวณ Window Function เช่น จัดอันดับ (RANK) หรือหายอดสะสม

BEGIN / COMMIT / ROLLBACK

ห่อหุ้มการเปลี่ยนแปลงเป็น Transaction เดียว ยกเลิกได้ทั้งชุด

UNION / UNION ALL

รวมผลลัพธ์จากหลาย Query เป็นชุดเดียว (ตัดซ้ำ / คงซ้ำ)

CREATE VIEW / INDEX

สร้างมุมมองข้อมูลใช้ซ้ำได้ และ Index เพื่อเร่งความเร็วการค้นหา

? Parameters (bind)

ผูกค่าเข้าคำสั่งแบบแยกส่วน — ทางออกมาตรฐานป้องกัน SQL Injection
